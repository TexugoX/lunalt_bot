# 🌙 Lunalt Bot

> Um bot de Telegram autônomo, rápido e eficiente para download de mídias de diversas plataformas sociais (YouTube, TikTok, Instagram e mais), alimentado por `yt-dlp` e Python.

## 🚀 Sobre o Projeto
O **Lunalt** nasceu para ser uma solução prática e direto ao ponto para baixar vídeos diretamente pelo chat do Telegram, operando 24 horas por dia na nuvem. Ele utiliza a poderosa biblioteca `yt-dlp` para extrair e processar os links com alta compatibilidade.

---

## 🛠️ Tecnologias Utilizadas
* **[Python 3](https://www.python.org/)** — Linguagem principal do projeto.
* **[python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot)** — Biblioteca assíncrona para integração com a API do Telegram.
* **[yt-dlp](https://github.com/yt-dlp/yt-dlp)** — Extração de vídeos e mídias de alta performance.
